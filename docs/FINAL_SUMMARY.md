### 2. 快捷键系统

**支持的快捷键：**
- `Ctrl/Cmd + Z` - 撤销
- `Ctrl/Cmd + Y` 或 `Ctrl/Cmd + Shift + Z` - 重做
- `Delete` / `Backspace` - 删除选中组件
- `↑` / `↓` - 选择相邻组件
- `Escape` - 取消选择
- `Ctrl/Cmd + S` - 保存
- `Ctrl/Cmd + D` - 复制组件

**智能处理：**
- 在输入框中时自动禁用快捷键
- 防止与浏览器默认行为冲突

## 🎯 使用流程

### 1. 安装依赖
```bash
pnpm install
```

### 2. 启动开发服务器
```bash
pnpm dev
```

### 3. 开始使用

**方式一：从零开始**
1. 从左侧拖拽组件到画布
2. 点击组件配置属性
3. 调整样式和布局

**方式二：使用模板**
1. 点击工具栏模板按钮
2. 选择预设模板
3. 修改内容

### 4. 保存和导出

**保存为 JSON：**
- 点击"保存"按钮
- 下载 JSON 文件

**导出为代码：**
- 点击"导出"按钮
- 选择 HTML 或 Vue
- 下载代码文件

**自动保存：**
- 数据自动保存到浏览器
- 刷新页面后自动恢复
