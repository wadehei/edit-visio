## 💡 使用流程

### 专业编辑工作流

1. **搜索组件**
   ```
   组件面板 → 搜索框 → 输入关键词 → 快速定位
   ```

2. **收藏组件**
   ```
   悬停组件 → 点击星标 → 收藏到顶部
   ```

3. **精确对齐**
   ```
   拖拽组件 → 自动显示对齐线 → 精确对齐
   ```

4. **添加动画**
   ```
   选中组件 → 动画面板 → 选择动画 → 调节参数
   ```

5. **右键操作**
   ```
   右键组件 → 选择操作 → 快速执行
   ```

6. **查看历史**
   ```
   历史面板 → 查看时间线 → 点击恢复
   ```
