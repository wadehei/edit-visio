## ✨ 新增创新功能

### 1. 🎯 多设备响应式预览

**功能特性：**
- 支持 4 种设备：手机（375×667）、平板（768×1024）、桌面（1920×1080）、自定义尺寸
- 一键切换设备，实时预览效果
- 自定义尺寸对话框，精确控制
- 设备图标可视化

**使用场景：**
- 验证页面在不同设备上的显示效果
- 确保响应式设计质量
- 快速适配多种屏幕

**代码位置：**
- `composables/useDevicePreview.ts` - 设备管理逻辑
- `components/DeviceSwitcher.vue` - 设备切换 UI

**功能特性：**

**技术实现：**
- 使用 `qrcode` 库生成高质量二维码
- 数据编码到 URL 参数
- 响应式更新机制

**使用场景：**
- 移动端真机测试

**代码位置：**
- `components/QRCodeModal.vue` - 二维码弹窗
- 依赖：`qrcode` + `@types/qrcode`

### 8. 📲 PWA 离线支持

**功能特性：**
- 可安装到桌面
- 离线访问

- 推送通知支持（预留）
- 快速加载

**技术实现：**
- `vite-plugin-pwa` 集成
- Service Worker 自动注册
- 智能缓存策略
- 字体资源缓存

**Manifest 配置：**
```json
{
  "name": "页面装修平台",
  "short_name": "页面装修",
  "theme_color": "#3b82f6",
  "display": "standalone",
  "icons": [...]
}
```

**使用场景：**
- 无网络环境使用
- 桌面应用体验
- 快速启动

**代码位置：**
- `vite.config.ts` - PWA 配置
- 依赖：`vite-plugin-pwa`
