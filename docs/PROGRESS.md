## 🎯 当前可用功能

### 已实现的用户操作

1. **添加组件**
   - 从左侧组件面板拖拽组件到画布
   - 支持 4 种基础组件：文本、按钮、图片、容器

2. **选择组件**
   - 点击画布中的组件进行选择
   - 选中的组件显示蓝色边框
   - 悬停时显示浅蓝色边框

3. **配置组件属性**
   - 根据组件类型显示对应的配置项
   - 文本组件：内容、颜色、字体大小、字重、对齐方式
   - 按钮组件：文字、类型、大小、块级、链接
   - 图片组件：地址、替代文本、宽高、填充模式、圆角
   - 容器组件：排列方向、间距、内边距

4. **配置组件样式**
   - 背景颜色
   - 内边距
   - 外边距
   - 圆角

5. **删除组件**
   - 选中组件后点击工具栏删除按钮
   - 或点击组件右上角的 × 按钮

6. **组件排序**
   - 在画布内拖拽组件改变顺序

7. **组件嵌套**
   - 在容器组件内添加子组件
   - 支持多层嵌套

8. **撤销/重做**
   - 支持 20 步历史记录
   - 工具栏按钮或快捷键

9. **保存页面**
   - 导出为 JSON 文件
   - 包含完整的页面 Schema

10. **预览**
    - 打开新窗口预览页面

## 🚀 如何使用

### 1. 安装依赖

```bash
pnpm install
```

### 2. 启动开发服务器

```bash
pnpm dev
```

### 3. 访问编辑器

打开浏览器访问：http://localhost:3000

### 4. 开始使用

1. 从左侧组件面板拖拽组件到画布
2. 点击组件进行选中
3. 在右侧属性面板配置组件属性和样式
4. 使用工具栏的撤销/重做、删除、保存、预览功能
